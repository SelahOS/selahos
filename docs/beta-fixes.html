Beta 2.0.1 Fix Script

Installer problems found by our first outside beta tester, already fixed for the next ISO. This script applies the same fixes to a system you have already installed from the Beta 2.0.1 ISO, so you don't have to reinstall.

New and lightly tested. Run it with --check first (it changes nothing), read what it reports, then apply. It needs root to apply and backs up every file it touches. If anything looks wrong, tell us at beta@selahos.io.

What it fixes

1. pacman -Sy fails on a fresh install

The installer copied two repositories into your installed /etc/pacman.conf that cannot work there: [selahos-offline] points at a folder that only exists on the live USB, and [chaotic-aur] has no signing key on your system. Pacman aborts the whole sync if any one repository fails, so updates and installs break until both are removed. The script disables both (they are only needed to build the live ISO).

2. Broadcom wl driver loads on non-Broadcom Wi-Fi

The wl driver matches any Wi-Fi card by PCI class, so on Intel, Atheros and other laptops it loaded anyway, tainted the kernel and printed a warning at boot. On machines with no Broadcom Wi-Fi chip the script blacklists it. On machines that do have one, it leaves your Wi-Fi driver configuration completely alone.

3. Missing packages

  • wireless-regdb — the regulatory database; without it Wi-Fi runs on the restrictive default region (no proper 6 GHz on Wi-Fi 6E).
  • rtkit and realtime-privileges — realtime scheduling for PipeWire, which audio work needs.
  • ksystemlog and discover — a log viewer and a software centre (Flathub is already configured).

How to run it

Download and confirm the checksum matches before running anything as root:

cd ~/Downloads
curl -fLO https://selahos.io/docs/downloads/selah-beta-fix-2026-09-19.sh
sha256sum selah-beta-fix-2026-09-19.sh

The checksum must be exactly:

592bbc46308544d06c402872f9f3b85e3131a4d434a090a5e97d4869a1767fc3

Then look first, apply second, and reboot:

sudo bash selah-beta-fix-2026-09-19.sh --check   # report only, changes nothing
sudo bash selah-beta-fix-2026-09-19.sh           # apply the fixes
reboot

It is safe to run twice; anything already fixed is reported as [ok]. You can read the source first on GitHub. Installing the packages needs a working network connection.

Safety & backups

  • Every file the script modifies is first copied to /var/backups/selah-beta-fix/ with a timestamp.
  • --check never modifies anything and does not need root.
  • It only touches /etc/pacman.conf, one file in /etc/modprobe.d/, and installs the packages listed above.

To undo the pacman change, copy the backed-up pacman.conf.* file back over /etc/pacman.conf.

Not covered by the script

These installer fixes go into the next ISO and can't be applied afterwards: carrying your keyboard layout and saved Wi-Fi network over from the live session (set them in System Settings for now), and the Selah Repair window staying open after it finishes. See also the Known Issues page and the Extras & Fixes worksheet.

Installing in a VM? The installer requires UEFI. In virt-manager choose UEFI (OVMF) firmware instead of the default BIOS; Secure Boot must stay off.
