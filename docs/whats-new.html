What’s New

Changes since the Beta 2.0.1 download of 9 September 2026. The download is still 2.0.1. Some of what’s below you can add to a system you have already installed, today. The rest arrives in the next ISO, Beta 2.0.1.1, which is not released yet.

Until 2.0.1.1 is released, the requirements on the download page still apply (UEFI firmware; see Known Issues).

Available now, for an existing install

  • Print Center — finds printers on your network, sets most of them up with no driver, and shows them in every app’s Print dialog. One script adds it to a system you have already installed. Revision 2 is current.
  • Beta Fix Script — fixes for install problems found by our first outside tester.

Coming in Beta 2.0.1.1 (not released yet)

2.0.1.1 is a fix revision of 2.0.1. Everything below is finished in the source and has been tested in virtual machines; it is not in the current download.

  • Install on computers that start in legacy BIOS mode. Beta 2.0.1 could finish installing on such a machine and then not start, because it only set up UEFI booting. The installer now detects how it was started and sets the drive up to match, and the same drive also starts on UEFI. Tested in virtual machines with both BIOS and UEFI firmware; not yet on real BIOS-only hardware.
  • A safer drive picker. It no longer lists things that can’t be install targets (floppy drives, compressed-RAM swap, read-only and tiny devices), and it no longer picks a drive for you when more than one could be the target — you choose.
  • Hostname check. The installer rejects a computer name with characters that break networking (for example an underscore).
  • A system check on the welcome screen. It shows the boot mode, memory and network status, with a note if something is worth knowing before you start (for example, low memory).
  • Better recovery. The selah-rescue boot-repair tool now repairs both UEFI and BIOS installs, checks that the repair worked, and looks for the boot partition on the same drive as the system you chose.
  • Print Center built in. Printer discovery and setup are part of the install, so printers work without running a separate script.

Still open

These are not fixed in 2.0.1.1: Wi-Fi that won’t connect, and silent internal speakers, on some Macs. They are being worked on with real hardware; see Known Issues for what we know and any workaround.
