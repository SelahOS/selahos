Print Center

Find your printer on the network, set it up, and print to it from any app. Most printers made since about 2015 (AirPrint / Mopria / “IPP Everywhere”) need no driver at all — SelahOS asks the printer what it can do and configures itself. This script adds the Print Center to a system you have already installed; it will also be built into the next ISO.

New, and tested on one printer. Discovery, setup and a printed test page have been checked on two computers (one of them a machine installed from Beta 2.0.1) against one printer, a Brother HL-L3230CDW color laser. Other printers are untested. Run the script with --check first, and tell us at beta@selahos.io what printer you have and how it went.

What you get

  • SelahOS Print Center in the application menu: lists your printers, shows toner or ink levels, prints a test page, sets the default printer, two-sided / color / paper-size defaults, and shows the print queue.
  • Network discovery. Printers on your Wi-Fi or Ethernet show up on their own, and there is an “enter its address” box for any that don't.
  • Every app can print. Firefox, LibreOffice, Okular, Kate and the rest all use the same system print service, so a printer set up here appears in their Print dialogs.
  • KDE's own Printers page in System Settings, and KDE's print-job applet.

It installs: cups, cups-filters, cups-browsed, ghostscript, avahi, nss-mdns, print-manager, gutenprint, ipp-usb (and python-pyqt6 if it is missing).

How to install it

Download it and confirm the checksum before running anything:

cd ~/Downloads
curl -fLO https://selahos.io/docs/downloads/selahos-print-center-install-2026-09-21-r2.sh
sha256sum selahos-print-center-install-2026-09-21-r2.sh

The checksum must be exactly:

26df4c932030ca9114aa7cc0a3829dd3a895d95a559a5751050078956db31bd5
Revision 2 (this page). Fixes two things found on its first run on a second computer: a setup step that could leave your admin account unable to add printers (the script now repairs CUPS's admin-group setting), and the script no longer says “Done” when its own final check reports a problem. If you already ran the first version (its checksum began 0e75267d), run this one over it — that is safe.

Look first, install second. Run it as your normal user — it asks for your password once:

bash selahos-print-center-install-2026-09-21-r2.sh --check   # report only, changes nothing
bash selahos-print-center-install-2026-09-21-r2.sh           # install

It is safe to run twice. You can read everything it installs first: bash selahos-print-center-install-2026-09-21-r2.sh --extract ~/print-center-source unpacks the programs without installing them, or just open the script in a text editor — the program sources are at the bottom. Installing needs a working network connection.

If it says your package database is out of date, run it again with --upgrade. That does a full system update first (pacman -Syu) — the supported way to fix this on Arch — so it updates everything, may rebuild DKMS drivers, and may want a reboot. Everything is logged to ~/selahos-print-center-install.log.

Using it

  1. Turn the printer on and make sure it is on the same network as your computer.
  2. Open SelahOS Print Center from the application menu (or run selahos-print-center). It scans your network.
  3. Click Add next to your printer. It is ready to use, and appears in every app's Print dialog.
  4. Can't see it? Type its IP address (shown in the printer's own menu or on your router's device list) into the box at the bottom of the Add page.

If printing ever stops working, use Repair printing at the top right of the window, or run the install script again.

Safety & undoing it

  • It installs two programs and a menu entry under /usr/local/bin and /usr/share/applications, plus the packages above.
  • It edits up to three system files — /etc/nsswitch.conf (so printers' .local names resolve), /etc/cups/cups-browsed.conf (so network printers are added automatically) and, only if its admin-group line is missing, /etc/cups/cups-files.conf (so your admin account can add printers) — and copies each to /var/backups/selah-print/ first.
  • It never modifies /etc/pacman.conf; it uses a temporary copy without the [selahos-offline] and [chaotic-aur] sections that break installs on installed systems (see the Beta Fix Script).
  • Printers are set up unshared: other computers on your network cannot print through yours.
  • --check never changes anything and does not need a password.

To undo it: restore the two files from /var/backups/selah-print/, then sudo systemctl disable --now cups-browsed cups avahi-daemon and sudo rm /usr/local/bin/selah-print /usr/local/bin/selahos-print-center /usr/share/applications/selahos-print-center.desktop. The packages are ordinary Arch packages; remove them with pacman -Rns if you wish.

Not covered yet

  • Older printers that need a maker's driver. The Print Center will say “will look for a driver” and searches the installed drivers (Gutenprint and others), but some older models — for example older Brother black-and-white lasers, which need brlaser — are not included yet.
  • Scanning and the scanner half of all-in-one printers.
  • Windows-shared (SMB) printers and printers behind a print server.
  • Auto-adding a printer the moment it appears on a fresh boot depends on the network services that this script turns on; it is verified on the printer we tested, not yet across brands.
